# 提醒推送 —— 不需要 n8n，也不需要别的服务

网页应用本身没法「主动弹通知到手机」，这是浏览器沙箱的限制。但服务器可以主动**发**出去，只需要一个你手机上已经有的接收端。下面四种任选其一，都是免费、国内可用、配置只要复制一串 key。

## 方案对比

| 方案 | 手机上怎么收到 | 需要准备 | 限制 | 适合 |
| --- | --- | --- | --- | --- |
| **企业微信群机器人** ⭐ | 微信群消息 | 建一个 2 人群，加机器人 | 每分钟最多 20 条 | 两个人共用，还能互相看见 |
| **Server酱** | 微信「方糖」服务号 | 微信扫码拿 SendKey | 免费版每天 5 条 | 只给自己推 |
| **PushPlus** | 微信服务号 | 微信扫码拿 token | 免费每天 200 条 | 量大 |
| **Bark** | iOS 通知中心 | 装 Bark App（开源） | 仅 iOS | 用 iPhone 的人 |
| Web Push | 系统通知 | 需要 HTTPS + 装 PWA | 有域名后才能用 | 以后升级 |

## 推荐：企业微信群机器人

理由：你们本来就有两个人的群，机器人发进去**双方都看得到**——「小雨完成了阅读」「你今天还有 2 件没做」这种消息，在群里比私聊更有推动力。

### 怎么拿 webhook

1. 手机或电脑企业微信 → 建一个群（把对方也拉进来，或者只拉一个「提醒机器人」群）
2. 群设置 → 群机器人 → 添加 → 起个名字（比如「Duet」）
3. 复制它给的 Webhook 地址，长这样：
   ```
   https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxxxxxx-xxxx-xxxx
   ```

把这个地址发我，我把它写进配置，然后：

- 每天早上 8:00 推「今天 N 件事」
- 晚上 21:00 推还没完成的
- 有人打卡 / 有兑换待发放时推一条

## 不想要微信的话

**Bark**（iPhone）：装 App → 复制 `https://api.day.app/你的key/` → 发我。
**Server酱**：微信扫码 → 复制 `https://sctapi.ftqq.com/你的key.send` → 发我。

## 实现方式（我这边怎么接）

服务器上已经有一个常驻的 Node 进程（systemd 管的）。我会加一个定时任务：

```
每 5 分钟检查一次：
  - 有习惯的 remindAt 到点了，且今天没打卡 → 推送
  - 每天 21:00 → 汇总今天的完成情况
  - 有新的待确认 / 待发放 → 推送
```

推送就是服务器发一个 HTTPS 请求出去，不依赖任何外部平台（n8n、第三方服务都不需要）。配置存在数据库里，在「设置 → 提醒推送」里能填、能测、能关。
