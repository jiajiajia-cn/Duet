# Duet

> 两个人的打卡账本 —— 一起打卡 · 积分换奖品（含合兑）· 专注计时 · 技能卡片 · 互相监督 · 日程 · 自习室
>
> 需求文档（docs/PRD.md）里的功能，除了「推送通知」需要部署后再做，其余都实现了。

## 跑起来

```bash
pwsh scripts/db-start.ps1     # 起项目自带的 PostgreSQL（5433，不需要管理员）

npm run build && npm start    # 生产模式 → http://localhost:3100（快，日常用这个）
npm run dev                   # 开发模式（改代码热更新，慢是正常的）

node scripts/seed.mjs           # demo@checkin.local / demo1234
node scripts/seed-history.mjs   # 3 周打卡 + 计时
node scripts/seed-rewards.mjs   # 6 个奖品 + 成员「小雨」
node scripts/demo-state.mjs     # 一单待发放 + 一张合兑 + 一条待确认 + 两个日程 + 一间自习室
```

| 账号 | 角色 | 用途 |
| --- | --- | --- |
| `demo@checkin.local` / `demo1234` | 圈主（小满） | 主视角 |
| `xiaoyu@checkin.local` / `demo1234` | 成员（小雨） | 试合兑、互相监督、自习室 |

## 功能清单（全部可用）

**习惯**
- 四种类型：普通打卡 / 计量（喝水 3 杯）/ 负向戒断 / 计时达标
- 频率：每天 / 每周指定几天 / 每周 N 次
- 打卡、撤销（反向流水 + 重算连续天数）、补打卡（近 7 天，不计连续）
- **一起打卡**：两个人都完成才算成功，成功后各得一份分；谁撤销了，两边一起回滚
- 连续天数、热力图、暂停 / 归档

**积分**
- 每个习惯自定义分值、单日上限
- 只追加的流水账本（余额、快照、对账字段）
- 连续里程碑奖励（7 / 30 / 100 天，同档只发一次）
- 圈主手动加分 / 扣分（写理由、通知对方、扣不到负数）

**奖品**
- 图片上传、自定义分类、库存、每人限兑、冷却期
- 兑换不审核：积分够就成立，扣分与建单同一事务
- **合兑**：发起 → 对方补分 → 凑齐成立；超时自动解散退分
- 订单状态机、标记发放、确认收到、取消退分、归档

**计时**
- 正计时 / 倒计时 / **番茄（专注 25 + 短休 5，每 4 轮长休 15）**
- 暂停、服务端结算（不信前端）、太短的会话自动丢弃
- 阶梯计分 / 按分钟 / 按次，规则你自己填
- 计时型习惯达标自动打卡（不重复发分）
- 事后再归类到技能

**技能卡片**
- 新建 / 编辑 / 归档；累计时长、等级、30 天柱图、12 周热力、最近记录

**监督**
- 习惯可设「打卡需要对方确认」→ 待确认 → 对方点头才加分
- 驳回带理由、催办（12 小时不重复）、通知中心

**日程**
- 今天 / 接下来 6 天；每天 / 每周 / 每月重复；分类颜色；预计时长
- 标记完成

**自习室**
- 创建 / 房间码加入 / **直接把圈内人拉进来（会发通知）**
- 房主开始 / 共同倒计时（服务端时间）/ 随时可关闭房间
- 结束后每人各自「记到我的时间」

**圈子**
- 邀请码 + 邀请链接（`/join/xxxxxx`），对方注册或登录后直接落在圈子里
- 一个人可以在多个圈子里，设置里随时切换
- 找不到圈子时有个引导页：自己开一个 / 用码加入
- 圈主可改名、换邀请码；成员可退出

**其它**
- **主题**：默认（紫）/ 白色 / 黑色 / 绿色 / 蓝色 / 粉色 / 线条小狗
- **线条小狗主题的小细节**：计时器中心有只小狗，专注时轻轻浮动、暂停时趴下睡觉；钱包卡、登录页、空状态、一起打卡成功各有对应的表情；打卡的勾会弹一下
- **头像与昵称**：设置里可以直接传图、改名字
- 设置中心（计分规则、圈子、账号、时区、日切时间）
- 数据导出（JSON 备份 / CSV 打卡记录）
- PWA（可安装到桌面）

## 每个功能在哪

| 想做什么 | 去哪儿 |
| --- | --- |
| **改昵称 / 头像** | 「我的」→ 设置 → 账号 |
| **设置一起打卡** | 习惯 → 点名字 → 一起打卡 → 勾上「两个人都完成才算成功」 |
| **自习室拉人 / 关房间** | 自习室 → 进房间 → 拉人进来 / 关闭房间 |
| 换主题 | 「我的」→ 设置 → 主题 |
| 打卡 / 撤销 | 底部「今天」 |
| 改习惯（频率、分值、要不要确认） | 「习惯」→ 点名字 |
| 改计时计分规则 | 「我的」→ 设置 → 计时计分规则 |
| 番茄 | 「计时」→ 🍅 番茄 |
| 日程 | 「今天」右上角「日程」，或设置 → 日程表 |
| 自习室 | 设置 → 自习室 |
| 补打卡 | 设置 → 补打卡 |
| 上架奖品 / 兑换管理 | 设置 → 奖品 |
| 确认别人的打卡 / 催办 | 设置 → 待确认 |
| 手动调分 | 设置 → 成员与积分 |
| 导出数据 | 设置 → 数据 |

## 还没做的

| 功能 | 说明 |
| --- | --- |
| **Web Push 推送** | 需要 HTTPS + 用户授权 + VAPID 密钥，本地开发验证不了，建议部署后做（半天） |
| 圈子周报 | 每周自动汇总，需要定时任务（半天） |
| ICS 导出 / 日历订阅 | 低频，可延后 |
| 空闲检测 | 桌面端判定不准，收益低 |

## 部署到线上

完整步骤见 docs/部署-CloudBase.md，核心就三步：

```bash
# 1. 本地先验一遍镜像（可选，需要 Docker）
docker build -t checkin .
docker run -p 8080:8080 -v checkin-data:/data \
  -e AUTH_SECRET=<随机串> -e LOCAL_PG=1 checkin

# 2. 推到 GitHub / Gitee，在腾讯云 CloudBase 里关联仓库
git remote add origin <你的仓库地址>
git push -u origin main

# 3. 云托管里填环境变量 + 挂载 /data 持久盘
```

上线后：注册第一个账号 → 设置 → 圈子 → 复制邀请链接发给对方。

清空演示数据从头开始：`node scripts/wipe-data.mjs --yes`，备份：`scripts/backup.ps1`。
## 技术栈

Next.js 15（App Router）+ React 19 + TypeScript + Prisma 6 + PostgreSQL 18（项目自带实例，端口 5433）。
部署时把 `DATABASE_URL` 换成 Supabase / 自建库即可；图片目前存 `public/uploads`，上云换对象存储。
